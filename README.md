# obd-boss-tools

Commande `pplx` pour iSH (iPad) : recherche web sourcée via l'Agent API Perplexity.

Installation (dans iSH) :

```bash
curl -fsSL https://raw.githubusercontent.com/etoileoubella-create/obd-boss-tools/main/install.sh | bash
source ~/.bashrc
```

Aucune clé n'est stockée dans ce dépôt : elle est demandée à l'installation et enregistrée uniquement dans `~/.bashrc` sur l'iPad.
